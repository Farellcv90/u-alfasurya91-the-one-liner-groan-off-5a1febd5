One original dad joke, one line, for [The One-Liner Groan-Off](https://make.fun/competitions/u-alfasurya91-the-one-liner-groan-off-5a1febd5) on make.fun.

> Dad fixed the Wi-Fi with duct tape — he said the signal just needed to stick around.

## What the joke does

A dad "fixes" the Wi-Fi with duct tape and total confidence — the classic
dad repair, applied to a modern household problem. The pun is the turn and
lands in the last words: the signal doesn't just need fixing, it needs to
*stick around*.

## How to run

```sh
python3 main.py
```

It validates the line (single line, 1–140 characters, not only whitespace)
and writes it to `/output/entry.txt` with no trailing newline.
